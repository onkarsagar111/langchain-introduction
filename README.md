# langchain-introduction
FIrst project on lang chain to understand the fundamental concepts of langchain

### Prerequisite
1. Python & pipenv (package manager and virtual environment) should be isntalled.
2. Pycharm / VS code

### Project setup 
1. Create a new repo.
2. Open it with your choice of editor
3. Run pipenv shell command to create virtual environment.
4. Install following dependencies with pipenv install <package-name> command.
5. Create new .py file.
6. 

### Dependencies
1. langchain
2. langchain-openai - package to integrate langchain with the LLMs provided by OpenAI.
3. langchain-community - package to utilize the community written code like output parsers.
4. langchainhub - pacakage to dynamnically download community contributed prompts to save prompt engineering efforts.
5. *black - package to format the code.

### Keywords
1. Virtual Environment - Going to contain all the dependencies that we need in order to run the project.
